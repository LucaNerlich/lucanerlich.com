# (DE) Download der kompletten GOG Bibliothek

Wer Spiele bei [GOG](https://www.gog.com) kauft, kann die verfügbaren Offline-Installer aus der
Bibliothek herunterladen. GOG Galaxy eignet sich gut zum Installieren und Aktualisieren, ersetzt aber kein
eigenes, überprüftes Archiv.

Die GOG-Weboberfläche bietet keinen offiziellen Ein-Klick-Export für eine komplette Bibliothek. Für größere
Archive gibt es Community-Tools. Prüfe vor dem Einsatz deren aktuelle Wartung, die GOG-Nutzungsbedingungen
und ihre Unterstützung für Zwei-Faktor-Authentifizierung -- diese Schnittstellen und Tools ändern sich.

1. **[gogrepoc](https://github.com/Kalanyr/gogrepoc)** / gepflegte Forks: Python-basierte Downloader
   für Offline-Installer und Zusatzinhalte.
2. **[LGOGDownloader](https://github.com/Sude-/lgogdownloader)**: vor allem für Linux interessant.
3. Manuell: Installer pro Spiel aus der GOG-Bibliothek herunterladen. Langsam, aber ohne ein
   Drittanbieter-Tool.

Dieser Beitrag zeigt ein konservatives Windows-11-Setup für **gogrepoc**. Die konkreten Abhängigkeiten
stehen in der README des gewählten Repositories; installiere sie nicht einzeln nach Fehlermeldungen und
führe keine fremden Skripte ohne Prüfung mit deinem Hauptkonto aus.

1. Installiere eine aktuelle Python-3-Version von [python.org](https://www.python.org/downloads/windows/).
   Prüfe sie in PowerShell mit `py --version`.
2. Klone oder lade das gewählte Repository in einen Ordner auf dem Ziellaufwerk, zum Beispiel
   `D:\gog-backups\gogrepoc`.
3. Erzeuge eine isolierte Python-Umgebung und installiere ausschließlich die vom Projekt dokumentierten
   Abhängigkeiten:

   ```powershell
   py -m venv .venv
   .\.venv\Scripts\python.exe -m pip install --upgrade pip
   .\.venv\Scripts\python.exe -m pip install html5lib requests psutil
   ```

4. Lies die README des verwendeten Forks für die aktuellen Login- und Downloadbefehle. Bei der
   ursprünglichen CLI ist der Ablauf typischerweise:

   ```powershell
   .\.venv\Scripts\python.exe gogrepoc.py login
   .\.venv\Scripts\python.exe gogrepoc.py update
   .\.venv\Scripts\python.exe gogrepoc.py download -lang en de
   .\.venv\Scripts\python.exe gogrepoc.py verify
   ```

5. Prüfe nach dem Download die vom Tool angebotenen Prüfsummen und bewahre die Installer, Metadaten sowie
   Kauf-/Serieninformationen gemeinsam auf. Führe bei der regelmäßigen Pflege zuerst `update`, dann
   `download` und anschließend `verify` aus, damit auch neu entdeckte oder geänderte Dateien heruntergeladen
   und geprüft werden.

:::tip[Archivstrategie]
Speichere das Archiv auf mindestens zwei physischen Medien oder nach der 3-2-1-Regel. Ein Backup ist erst
brauchbar, wenn du einen Installer auf einem separaten System testweise wiederherstellen kannst.
:::
